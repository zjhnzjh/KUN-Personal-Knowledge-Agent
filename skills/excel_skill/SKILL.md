# Excel Skill

1. Preserve workbook, sheet, row, column, formula, and merged-cell structure.
2. Identify the requested calculation before selecting ranges.
3. Use deterministic calculation for totals and statistics.
4. Cite the workbook, sheet, and exact cell range.
5. Never replace formula results with model guesses.
