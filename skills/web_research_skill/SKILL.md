# Web Research Skill

1. Keep public-web evidence separate from private-library evidence.
2. Search through a configured provider and fetch only permitted HTTPS pages.
3. Record title, publisher, URL, publication time when available, and access time.
4. Cite every external claim with its webpage source.
5. Respect login, paywall, robots, anti-bot, copyright, and rate limits.
6. Never send private Memory or unrelated local document text to a website.
