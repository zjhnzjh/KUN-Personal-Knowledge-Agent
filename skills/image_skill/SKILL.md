# Image Skill

1. Analyze the image before the import-confirmation step.
2. Produce an objective description, OCR text, and short tags.
3. Derive the proposed title and summary from the description and OCR.
4. Wait for confirmation before writing the searchable index.
5. Use `image.search` for semantic, OCR, and tag retrieval.
6. Do not infer unreadable text or hidden personal attributes.
